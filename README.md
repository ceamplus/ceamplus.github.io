# CEAM+ GitHub Pages

CEAM+ (Cognitive Ethical AI Adoption Model Plus) is a human-centered framework
that reduces cognitive overload, improves structured decision-making, and
supports ethical AI adoption across business, education, healthcare, and
rehabilitation systems through guided workflows and adaptive support.

## Files

- `index.html` contains the static page markup.
- `styles.css` contains the responsive visual system.
- `script.js` adds sticky header polish and local form feedback.

The site is ready for GitHub Pages and does not require a build step.
