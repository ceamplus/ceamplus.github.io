# CEAM+ GitHub Pages

CEAM+ (Cognitive Ethical AI Adoption Model Plus) is a human-centered research
framework for understanding how people and organizations adopt, resist, and
sustain change in an increasingly AI-driven world.

The framework is organized around stable foundational anchors, a supporting
research library, exploratory ideas, and a three-level research agenda. Its core
mission stays stable while technologies, research questions, and applied
contexts continue to evolve.

## Files

- `index.html` contains the static page markup.
- `styles.css` contains the responsive visual system.
- `script.js` adds sticky header polish and local form feedback.

The site is ready for GitHub Pages and does not require a build step.
